# LLM이란

LLM(Large Language Model, 대규모 언어 모델)은 방대한 텍스트 데이터로 학습되어, 사람의 언어를 이해하고 생성할 수 있는 인공지능 모델입니다.

## 핵심 특징

- **다음 토큰 예측**: LLM의 기본 동작은 "지금까지의 텍스트 다음에 올 가장 그럴듯한 토큰(단어 조각)"을 예측하는 것입니다. 이 단순한 원리가 대규모로 확장되면 번역, 요약, 코딩, 추론 같은 복잡한 능력으로 나타납니다.
- **범용성**: 하나의 모델이 별도 재학습 없이 질문 답변, 글쓰기, 코드 작성, 분석 등 다양한 작업을 수행합니다.
- **문맥 학습(In-context learning)**: 프롬프트에 예시나 지시를 넣어주는 것만으로 새로운 작업 방식을 즉석에서 따라 합니다.

## LLM이 잘하는 일

- 글 요약, 번역, 문체 변환
- 질문에 대한 설명과 답변
- 코드 작성, 리뷰, 디버깅
- 브레인스토밍, 초안 작성
- 비정형 텍스트에서 정보 추출·분류

## LLM의 한계

- **환각(Hallucination)**: 사실이 아닌 내용을 그럴듯하게 생성할 수 있습니다. 중요한 정보는 반드시 검증이 필요합니다.
- **지식 컷오프**: 학습 시점 이후의 정보는 모릅니다. 최신 정보가 필요하면 검색이나 [RAG](../guides/rag.md)를 결합해야 합니다.
- **컨텍스트 제한**: 한 번에 처리할 수 있는 텍스트 길이(컨텍스트 윈도우)에 상한이 있습니다.
- **계산·논리의 불안정성**: 복잡한 산술이나 엄밀한 논리 검증은 도구(계산기, 코드 실행) 연동이 더 안정적입니다.
