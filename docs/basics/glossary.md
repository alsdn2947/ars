# 용어 사전

LLM 관련 문서에서 자주 등장하는 용어를 정리합니다. 가나다/알파벳 순.

| 용어 | 설명 |
|------|------|
| 컨텍스트 윈도우 (Context Window) | 모델이 한 번에 처리할 수 있는 토큰의 최대량. 입력과 출력을 합친 크기 |
| 토큰 (Token) | LLM이 텍스트를 처리하는 최소 단위. 단어 또는 단어 조각 |
| 파인튜닝 (Fine-tuning) | 사전 학습된 모델을 특정 데이터로 추가 학습시키는 것 |
| 환각 (Hallucination) | 모델이 사실이 아닌 내용을 그럴듯하게 생성하는 현상 |
| Embedding (임베딩) | 텍스트를 의미를 담은 숫자 벡터로 변환한 것. 의미 기반 검색의 핵심 |
| Few-shot | 프롬프트에 예시를 몇 개 넣어 작업 방식을 보여주는 기법 |
| Inference (추론) | 학습된 모델이 실제로 출력을 생성하는 과정 |
| MCP (Model Context Protocol) | LLM 애플리케이션과 외부 도구·데이터를 연결하는 표준 프로토콜 |
| Prompt (프롬프트) | 모델에 주는 입력 텍스트(지시, 질문, 예시 등) |
| RAG (Retrieval-Augmented Generation) | 외부 문서를 검색해 프롬프트에 넣어 답변 품질을 높이는 기법 |
| RLHF | 사람의 피드백을 이용한 강화학습. 모델이 선호되는 답변을 하도록 조정 |
| SFT (Supervised Fine-Tuning) | 질문–답변 예시 데이터로 하는 지도 미세조정 |
| System Prompt (시스템 프롬프트) | 대화 전체에 적용되는 역할·규칙을 정의하는 프롬프트 |
| Temperature | 출력의 무작위성을 조절하는 파라미터. 낮을수록 일관적, 높을수록 다양 |
| Zero-shot | 예시 없이 지시만으로 작업을 수행하게 하는 것 |
