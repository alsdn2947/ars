# LLM의 동작 원리

## 1. 토큰화 (Tokenization)

LLM은 텍스트를 **토큰**이라는 작은 단위로 쪼개서 처리합니다. 토큰은 단어일 수도, 단어의 일부일 수도 있습니다.

- 영어는 대략 단어 1개 ≈ 1~2토큰
- 한국어는 같은 내용이라도 영어보다 토큰 수가 더 많아지는 경향이 있습니다.

토큰 수는 비용과 컨텍스트 제한에 직결되므로 실무에서 중요한 개념입니다.

## 2. 트랜스포머 (Transformer)

현대 LLM은 대부분 **트랜스포머** 아키텍처를 기반으로 합니다. 핵심은 **어텐션(Attention)** 메커니즘으로, 문장 안의 모든 토큰이 서로 어떤 관련이 있는지를 계산해 문맥을 파악합니다.

예를 들어 "그 은행은 강가에 있다"라는 문장에서 '은행'의 의미를 판단할 때, 어텐션은 '강가'라는 단어에 주목해 금융기관이 아닌 강둑(江岸) 쪽 의미를 선택하도록 돕습니다.

## 3. 학습 과정

일반적으로 세 단계를 거칩니다.

| 단계 | 이름 | 내용 |
|------|------|------|
| 1 | 사전 학습 (Pre-training) | 인터넷 규모의 텍스트로 "다음 토큰 예측"을 학습. 언어와 세상 지식의 기반이 형성됨 |
| 2 | 지도 미세조정 (SFT) | 사람이 만든 질문–답변 예시로 "지시를 따르는 법"을 학습 |
| 3 | 선호 학습 (RLHF/DPO 등) | 사람이 선호하는 답변 스타일을 학습해 유용하고 안전한 응답을 하도록 조정 |

## 4. 추론 (Inference)

학습이 끝난 모델이 실제로 답변을 생성하는 과정입니다. 한 번에 한 토큰씩 생성하며, 생성된 토큰이 다시 입력에 포함되어 다음 토큰을 예측합니다.

주요 파라미터:

- **Temperature**: 값이 낮으면 일관되고 예측 가능한 출력, 높으면 다양하고 창의적인 출력이 나옵니다.
- **Max tokens**: 생성할 최대 토큰 수 제한입니다.
- **컨텍스트 윈도우**: 입력 + 출력을 합쳐 모델이 한 번에 다룰 수 있는 토큰 총량입니다.
