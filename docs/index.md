# LLM Wiki

LLM(Large Language Model, 대규모 언어 모델)에 관한 지식을 정리하는 위키입니다.

## 이 위키의 목적

- LLM의 기본 개념과 동작 원리를 이해하기 쉽게 정리합니다.
- 프롬프트 엔지니어링, RAG, 파인튜닝, 에이전트 등 실전 활용법을 다룹니다.
- 빠르게 변하는 분야인 만큼, 누구나 수정·보완할 수 있는 문서로 유지합니다.

## 문서 기여 방법

1. `docs/` 아래에 마크다운 파일을 추가하거나 수정합니다.
2. 새 문서를 추가했다면 `mkdocs.yml`의 `nav` 항목에 등록합니다.
3. 커밋 후 푸시하면 됩니다. 로컬 미리보기는 `mkdocs serve`로 할 수 있습니다.
