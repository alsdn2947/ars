# 주요 모델 개요

!!! warning "주의"
    LLM 분야는 변화가 매우 빠릅니다. 구체적인 모델 버전, 성능, 가격은 금방 낡은 정보가 되므로 반드시 각 제공사의 공식 문서에서 최신 정보를 확인하세요. 이 문서는 큰 그림만 다룹니다.

## 상용 API 모델

클라우드 API로 호출해 쓰는 모델들입니다. 인프라 관리가 필요 없고 최고 수준의 성능을 제공합니다.

| 제공사 | 대표 계열 | 공식 문서 |
|--------|-----------|-----------|
| Anthropic | Claude | <https://docs.claude.com> |
| OpenAI | GPT | <https://platform.openai.com/docs> |
| Google | Gemini | <https://ai.google.dev> |

각 제공사는 보통 **고성능 모델**(복잡한 추론·코딩용)과 **경량 모델**(빠르고 저렴, 단순 작업용)을 함께 제공합니다.

## 오픈 웨이트 모델

가중치가 공개되어 직접 서버에 내려받아 실행할 수 있는 모델들입니다. Llama(Meta), Qwen(Alibaba), Mistral, DeepSeek 계열 등이 대표적입니다.

- **장점**: 데이터가 외부로 나가지 않음, 커스터마이징([파인튜닝](../guides/fine-tuning.md)) 자유, 대량 사용 시 비용 절감 가능
- **단점**: GPU 인프라와 운영 부담, 최상위 상용 모델 대비 성능 격차가 있을 수 있음
- 로컬 실행 도구: Ollama, vLLM, llama.cpp 등

## 모델 선택 기준

1. **작업 난이도**: 복잡한 추론·코딩이면 고성능 모델, 분류·추출 같은 단순 작업이면 경량 모델로 비용을 아낍니다.
2. **비용**: 토큰당 과금이므로 트래픽이 많다면 경량 모델·캐싱·오픈 모델을 검토합니다.
3. **데이터 정책**: 민감 데이터라면 오픈 웨이트 모델의 자체 호스팅이나 제공사의 데이터 처리 정책을 확인합니다.
4. **컨텍스트 길이**: 긴 문서를 다뤄야 한다면 컨텍스트 윈도우가 큰 모델이 필요합니다.
5. **실측 평가**: 벤치마크 점수보다 자신의 실제 작업으로 직접 비교 평가하는 것이 가장 정확합니다.
